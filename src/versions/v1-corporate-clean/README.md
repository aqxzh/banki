# HR Система - Версия 1 (Корпоративный чистый дизайн)

**Дата создания:** 29 октября 2025  
**Статус:** Сохраненная версия

## Описание

Это сохраненная версия HR-системы с профессиональным корпоративным дизайном.

### Основные характеристики дизайна:

**Цветовая схема:**
- Белый фон: #FFFFFF
- Синий акцент: #2563EB
- Зеленый: #10B981
- Красный: #EF4444
- Оранжевый: #F59E0B
- Темно-серый текст: #1E293B
- Светло-серые границы: #E2E8F0

**Стиль:**
- ❌ Без градиентов на фоне и карточках
- ❌ Без цветных теней
- ❌ Без "игрушечных" элементов
- ✅ Чистые белые фоны
- ✅ Простые серые рамки
- ✅ Минималистичные разделители
- ✅ Строгий корпоративный вид

**Основной функционал:**
- Поиск в реальном времени по имени, должности, ID
- Фильтрация по 27 сферам деятельности
- Сортировка по имени, категории, возрасту
- Бейджи категорий (C-1/C-2/C-3) в списке сотрудников
- Иконки образования 🎓 и опыта ⏱️ с подсказками возле каждого сотрудника
- Детальная информация в виде 4 блоков

## Файлы

- `HRWireframe.tsx` - основной компонент системы
- `EmployeeDetailsPanel.tsx` - правая панель с деталями сотрудника
- `README.md` - этот файл

## Как вернуться к этой версии

Просто скопируй содержимое файлов из этой папки обратно в `/components/`:

```bash
# Из папки versions/v1-corporate-clean в components
cp HRWireframe.tsx ../../components/
cp EmployeeDetailsPanel.tsx ../../components/
```

## Изменения от предыдущих версий

1. Убраны все градиенты
2. Убраны цветные тени (shadow-blue-100, shadow-green-100)
3. Убраны hover-эффекты с увеличением тени
4. Простые границы вместо цветных акцентов
5. Добавлены аккуратные обводки иконкам образования/опыта
6. Убраны иконки из шапки списка (они выглядели неестественно)
